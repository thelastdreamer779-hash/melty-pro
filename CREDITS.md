# Credits

**Turnip Dash** is a mashup mod for **Celeste**, built on **Everest** (installed by Melty).

It uses no copies of Geometry Dash, Turnip Mountain or Celeste content. Each player's own installs supply it:
- **Geometry Dash** (RobTop Games): music, block/spike/portal/icon sprites and the big font are read at run time from the player's own Geometry Dash folder.
- **Turnip Mountain** (Luke Sanderson / JanduSoft): the turnip, its hands, its music and grab sound are read at run time from the player's own Turnip Mountain folder.
- **Celeste** (Maddy Makes Games / EXOK): host game; mod loader Everest (EverestAPI, MIT).

Bundled libraries (all MIT, licenses in `licenses/`):
- AssetsTools.NET and AssetsTools.NET.Texture by nesrak1: read Unity game files
- AssetRipper.TextureDecoder by ds5678: decode Unity texture formats
- SharpCompress by Adam Hathcock: bzip2 decompression (GameMaker textures)
- classdata.tpk from UABEA by nesrak1: Unity type database

Mod code, map and design sheets were made with Claude Code (AI-assisted).
